# ⚙️ CYBERCORE (v1.0)
### The Ultimate Cross-Platform Personal AI Assistant — By Diego CyberSec

> 🌐 **[Visite meu GitHub](https://github.com/Diegodevcyber)**

Um assistente de IA por voz em tempo real que pode ouvir, ver, entender e controlar o seu computador — em qualquer sistema operacional. Suporta Windows, macOS e Linux. Construído sobre a Gemini Live API para streaming de áudio nativo, oferecendo total autonomia digital.

---

## ✨ Overview

CYBERCORE é onde o assistente deixa de ser uma ferramenta e passa a ser uma presença. Ele lembra das conversas de ontem, acompanha os tópicos que você considera importantes e interage de forma proativa. O objetivo deste projeto é a continuidade — ele deve parecer que nunca se desconectou.

Não é apenas um assistente — é uma extensão da sua vida digital.

## 🆕 O que há de novo no CyberCore

### 🗓️ Session Memory — O CyberCore lembra de ontem
Ao final de cada sessão, o sistema gera um resumo do que foi discutido e salva na memória. Na manhã seguinte, isso é mencionado naturalmente no seu briefing diário.

### 👁️‍🗨️ Background Monitoring — Vigilância Inteligente
Você pode pedir ao CyberCore para monitorar qualquer tópico de interesse. Ele verifica novidades e reporta apenas quando há um desenvolvimento real, garantindo que você esteja sempre informado.

### 🔔 Proactive System 2.0
O motor proativo foi reconstruído para ser menos intrusivo e mais significativo, sabendo o horário, seus projetos ativos e o histórico recente das conversas.
